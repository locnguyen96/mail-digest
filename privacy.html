Privacy Policy

Mail Digest is a private tool used only by its owner.

  • Data accessed: emails in the owner's own Gmail account, via the Gmail API.
  • Use: selected emails are read to create personal notes; processed emails are marked as read.
  • Storage: notes are kept only in the owner's private workspace. OAuth tokens are stored locally on the owner's computer.
  • Sharing: no data is sold, shared with, or disclosed to third parties.
  • Google user data use complies with the Google API Services User Data Policy, including the Limited Use requirements.
